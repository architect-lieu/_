# 东京社畜半年才发现富士山就在眼前
日本工作已经大半年了，今早又是例行的周出社日。
昨天看了100%降雨率，但早上出门竟是一片雨过天晴，心情瞬间好转一大半。

到公司刚坐下，宽大的窗外瞥见一角远处，阿！那是…富士山？！
只见远处的地平线，浮云深处若隐若现地浮出富士山上半身，只可能是它无疑了。
东京海拔接近海平面，平时只在城市的热岛看到晴朗天空，远处的天都是云气。这也难怪这么久都没发现它的真容。

旁边的女同事温柔地惊叫一声 阿，富士山耶？！好像她也是在这个视角初看富士山远景。富士山在日本人的地位好比泰山五岳在中国人心里的分量，

我说我是第一次看，她说 轰多？

事实上确实是，除了工作居住这年，之前旅行日本前前后后也有六次，从来没有去过富士山，也从没想过要去。对于从小山里生山里长的人，旅行一不看山二不看水，长久以来纯粹理性地生活已经失去了大部分发现美好的能力。而现在这座无人不知的休眠火山就如画卷呈现在眼前，不用去找，它就在那里。
突然按捺不住冲动，等明年樱花开的季节，一定要去富士山看看！

#日本是世界上最奇怪的国家（没有之一）
从2015年学日语，2017年考了N2，因为各种原因，赴日的行程便一搁再搁。2019年本来已经收拾好一切行囊，又遇到大感冒时期，三年没有出国。

从第一次以游客身份落在成田机场，至今在日本生活大半年，
最深刻也最隐忍的感觉就是，日本是个奇怪的国家，相当奇怪。奇怪到当时你想说它奇怪时又觉得正常，反复告诉自己 ^这也没什么大不了的^，但是只要你试图去接受它给的一切，又会觉得处处拧巴，这个社会的底层规则和自己过意不去。

每个初到日本，或多或少都会带着岛国滤镜，无非就是干净，礼貌，文明的表象，那些未来过日本但有兴趣的人，得到的言传也逃不过这些词。而且，一致共识是在日本国名前默契地加一个【小】字——即小日本。

我母亲只上过初中肄业，没有出过国。
她说 【哦呦 这点小日本 真不得了 我们读书那会，老师讲了个故事，说有中国人去日本旅游，上厕所不冲，最后被一个日本小孩看到，进去把厕所冲得干干净净。】

这个不知真伪的谣传她至少给我讲过三遍，分别在我人生的不同时期，一次是儿时，一次是我学日语的时候，一次就是我人在日本了。在她那个年代，偏远乡下，任何国家都是遥不可及的天方夜谭。想必是她那个年代的老师给她植入的思维定势，让她一生忘不掉这个《真实》的记忆。

日本是一个 工作的 国家
你可能觉得这不是很正常吗？哪个国家不要工作？
是的，所以说日本的工作比其他国家的工作还要工作。
在中文语境里，敬业 已经是对认真工作的的高度肯定。但这标准用在日本人身上，勉强算及格水平。日本人对于工作有非常强烈的道德耻感，
O tsu ga re sama
同样在简中语境里，提及工作轻松或繁重没什么褒贬，是中立的表达。甚至很多人期望的工作本就是轻松应对的，谁喜欢做繁重的工作呢？

在我提离职的时候，我本想早几个月离开。于是和人事商量，
他的意思是项目我的离开也许导致项目各个环节受影响之类，当然在我看来我的重要性远没有他想得程度，
我差点就说出我不想在团队里混日子了，早点走也是给Team省点经费，这是我暗自寻思的。
当我稍微表达一点这段时间Team的工作还挺 轻松 的，我只是说没有说的那么忙碌，对面一向温和的小哥脸色骤然大变，好像受到了侮辱。
给我吓一激灵，甚至忘了他是怎么回我的话。
我平时都很防备在与同事交流中不踩坑，你搁着等着我呢是吧？心里暗自叫苦，赶紧岔开话头，那就安心再留几个月，强行喂的Offer谁能不要呢？


日本人眼里，工作本身的价值感远高于工作本身，不论你在任何行业，从事任何工种，工作就意味着你已经被赋予责任，义务和使命。你必须是为某个对象或集体而工作。比如是你是销售，顾客是你的对象；你是工人，工厂和所有人都是工作的对象，你是在为大集体而工作，你不能有任何自主意识而不顾及集体。
也就是说，你不能是在为自己工作，日本人思维里没有这个概念。


日语把初级职业称为 xx担当 或 从业员，
